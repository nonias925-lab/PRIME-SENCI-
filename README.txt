PRIME SENCI Android project

This is an Android Studio project source, not a precompiled APK.
To build:
1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Debug APK will be at app/build/outputs/apk/debug/app-debug.apk.

GitHub Actions alternative:
Upload this project to a GitHub repository. The workflow at .github/workflows/build-apk.yml builds a debug APK. Download it from Actions > latest workflow run > Artifacts > PRIME-SENCI-APK.

App opens as a standalone fullscreen Android app. Login password: 444.
